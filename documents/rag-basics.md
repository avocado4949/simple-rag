# RAG 기초

RAG(Retrieval-Augmented Generation)는 정보 검색과 자연어 생성을 결합한 방식입니다.

## 1. 문서 로딩
외부 문서에서 데이터를 읽습니다. 이 예제는 Markdown 파일과 텍스트 파일을 지원합니다.

## 2. 청킹
긴 문서를 여러 청크로 나눕니다. 일부 구간을 서로 겹치게 하여 문맥 단절을 완화합니다.

## 3. 임베딩
청크를 임베딩 모델을 통해 벡터로 변환합니다. 이 실습에서는 Ollama의 bge-m3 모델을 사용합니다.

## 4. 색인 저장과 검색
문서 청크와 벡터를 JSON 파일로 저장합니다. 사용자의 질문도 같은 모델로 임베딩하여 코사인 유사도 기준으로 관련 청크를 찾습니다.

## 5. 답변 생성
질문과 검색된 청크를 LLM에 제공합니다. 모델은 문서 내용을 바탕으로 답변을 만들고 출처를 표시하도록 지시받습니다.

## 주의
검색된 문서가 잘못되었거나 답을 포함하지 않는다면 RAG도 부정확한 답변을 생성할 수 있습니다.
